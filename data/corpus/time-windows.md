# Customer delivery time windows

A promised delivery window is the period shown on the order, not an estimated arrival time. Dispatch sequences stops to meet each window and checks progress at the midpoint of every route. If a delay makes a window unlikely, the coordinator updates the recipient before the window closes and offers the next available option. Drivers should not promise a precise arrival minute or change a delivery window on the recipient's behalf. Record any agreed change in the route app so the next shift can see the current commitment.
